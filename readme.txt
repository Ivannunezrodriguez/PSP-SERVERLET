
PSP-SERVERLET
Este proyecto es una aplicación desarrollada en Java, como parte de las actividades del módulo de Programación de Servicios y Procesos (PSP). La aplicación implementa un servidor utilizando servlets para manejar solicitudes HTTP.

🧠 Descripción
La aplicación utiliza servlets para manejar solicitudes HTTP y proporcionar respuestas dinámicas. Es una introducción práctica al desarrollo de aplicaciones web utilizando Java EE y servlets.
